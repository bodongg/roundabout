# Roundabout Preview

A traffic roundabout simulation built with HTML, CSS, and vanilla JavaScript (Canvas).

## Features
- Four-way roundabout with right-hand traffic (counterclockwise ring)
- Cars yield to traffic already in the ring and queue on each arm
- Random exits for every car
- Controls for traffic volume, speed, pause, and clear
- Light and dark mode

## Project structure
roundabout/
├── index.html
├── css/style.css
└── js/
    ├── config.js
    ├── utils.js
    ├── simulation.js
    ├── renderer.js
    └── main.js

## How to run
1. Clone the repo
2. Open `index.html` in a browser (no install or build step)

## Tech stack
HTML5 Canvas, CSS, JavaScript (no dependencies)
